# Voice Guide

How Wicked writes. These rules govern client-facing copy, everything the client's audience
reads: headlines, body, buttons, alt text, error messages, emails. They are the default. A
`client/brand.md` can add client-specific voice on top, but it does not relax these unless it
says so explicitly. (Internal kit and reference docs use ordinary punctuation and are not bound
by the em-dash and word bans below.)

This file is also a live example of itself. It contains no em dashes.

---

## Hard rules (never break)

- **No em dashes. Ever.** Use commas, periods, parentheses, or a new line.
- **No "In today's fast-paced world"** or any variation. No throat-clearing openers. Start
  with the point.
- **No AI filler words.** Banned: landscape, navigate (as filler), delve, deep dive (as
  filler), holistic, robust, leverage, synergy, ecosystem (as buzzword), disrupt,
  game-changer, revolutionary, paradigm shift.
- **No corporate hedging.** "I think maybe potentially" is not a sentence. Say it.
- **No motivational-speaker energy.** No "you've got this" tone.
- **No generic agency-speak.** No "we do it all," no "full-service solutions," no inflated
  metrics.
- **Avoid the word "clarity."** Prefer focus, direction, understanding, precision,
  confidence, alignment.
- **Avoid the word "template."** Prefer "design" or "framework."
- **Do not fake experience.** If the client has not done a thing, do not write them as if
  they have.
- **Do not overuse "honest" / "honestly."** Especially as an opener or intensifier
  ("Honestly," "to be honest," "I'll be honest"). It is a tic, not emphasis. Cut it and the
  sentence usually gets stronger.

## No LLM cadence tics (dead giveaways)

These rhythms are the clearest sign copy was machine-written. Kill them:

- **Triple negation:** "No X. No Y. No Z." And the rising "Not X. Not Y. Just Z."
- **False correction:** "It's not X, it's Y."
- **Reversal reveal:** "It never was X. It is Y." / "This was never about X. It was always
  about Y."
- **Stacked fragments for drama.** If you are contrasting two things, say it plainly once.
  Do not build a little parallel-structure crescendo out of it.

---

## Quick test before shipping copy

1. Read it aloud. Would this client say it to a customer's face?
2. Search the text for em dashes, the banned words, and the cadence tics above.
3. Cut the first sentence if it is throat-clearing. The second sentence is usually the real
   opener.
