# Pages

One spec per page. Copy the template below into a new file named for the page (`home.md`,
`wholesale.md`, `shop.md`). A page spec is the bridge between the client context and the
Figma build: it says what this specific page is for and what is on it.

Keep specs short. They point at the context and the design system; they do not repeat them.

---

## Page spec template (copy this)

```
# [Page name]

## The page's single job
[The one thing this page exists to do. Not a list. See client/brief.md.]

## Primary audience for this page
[Who lands here and in what state of mind. See client/audience.md.]

## Sections (in order)
1. [Section] — [its job, key content, the one action]
2. [Section] — [...]
3. [...]

## The signature moment
[The one element on this page that carries personality. Spend boldness here.]

## Notes / constraints
[Anything specific: must include X, links to Y, a hard requirement from the brief.]

## Status
- Figma frame: [link]
- Gate: [not started / in design / brand approved / styles approved / page approved]
```
